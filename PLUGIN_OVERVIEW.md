Switch threads from the thread header.

## What you get

- Click the thread name at the top of a thread. A dropdown opens with every
  active thread. The thread that most recently needed attention is first.
- Each row shows the bb status glyph, the thread name, the project and branch,
  and the time since the thread last needed attention.
- Type to filter by name, project, or branch. Use the arrow keys to move,
  Enter to open, Cmd/Ctrl+Enter to open in a split, and Esc to close.
- Double-click the thread name to rename it, as before.

## How it works

The plugin runs only in the bb app. It reads the same thread list as the bb
sidebar, so it stores no data and makes no extra requests.
